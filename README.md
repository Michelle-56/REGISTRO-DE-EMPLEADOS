el programa esta creado para un Registro de Empleados con el fin de llevar un orden de una empresa 
estos son los pasos 
- Inicia el programa y crea la lista de empleados.
- Muestra el menú con 5 opciones.
- El usuario selecciona una opción.
- El programa ejecuta la acción con los siguientes enunciados:

1: Agregar empleado.
2: Listar empleados.
3: Buscar empleado.
4: Calcular factorial.
5: Salir.
Después de cada opción, regresa al menú.
El programa continúa hasta seleccionar 5. Salir.
Finaliza el programa.

cada opción esta diseñada para guardar los datos personales de cada empleado, así como su salario de cuanto gana cada mes y por hora y otros que tienen hora extras son contadas inmediatamente, así como el calculo factorial, podremos encontrar "Dato no invalido" ya que el programa esta diseñado para ser números positivos y no negativos.
en la opcion 1 podras encontrar que cada empleado sera agregado a su nombre "Juan Perez" horas extras y su salario
en opcion 2 podras encontrar que se encarga de enlistar cada empleado con su informacion respectiva 
en la opcion  3 esta encargada de buscar cada empleado 
en la opcion 4 es la encargada de calcular lo factorial sera siempre valido siempre y cuando el numero sea positivo, al ser negativo directamente marcara "Dato No valido"
en la opcion 5 es la encargada de ejecutar que els programa termine
